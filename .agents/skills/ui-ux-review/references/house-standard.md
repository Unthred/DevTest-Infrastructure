# House standard

These are the homeowner's stated preferences. Project design docs add
detail. Where they conflict, flag it rather than choosing silently.

- Use summaries and graphics with drill-down, not long scrolling pages.
- Group areas with a menu or nav bar. Provide back navigation from
  drill-downs and a back-to-top control.
- Paginate long lists.
- Tables have sortable headers, and footers with totals where it makes
  sense.
- Charts and graphs are large.
- Cards can be collapsed, rearranged and resized.
- Keep overall content width the same across pages where possible.
- Status and meta information use designed badges and indicators, not
  plain text.
- Make clear what the system is doing, will do next, and any issues,
  warnings and actions needed.
- Use a separate phone layout that works well, not a shrunken desktop
  page.
- Scrollbars are subtle and show on hover.
- Refer to items by one consistent name everywhere.
- Use SquigOS branding (title and lockup treatment), with each app's own
  icon.
- Polished as well as functional.
